# Movie Data Analysis

## Project Overview
This is a Python-based Movie Ratings Data Analysis project. It analyzes movie ratings, genres, directors, budgets, and revenues using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Features
- Data Loading and Cleaning
- Handling Missing Values
- Movie Ratings Analysis
- Genre-wise Movie Analysis
- Director-wise Rating Analysis
- Year-wise Movie Trends
- Budget and Revenue Analysis
- Data Visualization

## Dataset
The project uses a synthetic movie ratings dataset in CSV format.

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Run the Python file:
   `python movie_ratings_analysis.py`
